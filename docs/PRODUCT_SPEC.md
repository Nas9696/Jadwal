# مواصفات المنتج — الجداول الذكية

## 1. إعداد المنشأة
يدعم النظام مؤسسة تعليمية واحدة أو مجمعًا أو عدة مدارس تحت حساب واحد. لكل مدرسة: النوع، المراحل، الفترات، العام الدراسي، الفصل الدراسي، أنماط الأسابيع، أيام العمل، عدد الحصص، أوقات الحصص، الفسح، الصلاة، النشاط، والحضور/عن بعد.

## 2. البيانات الأساسية
- المعلمون: الاسم، المعرّف، التخصص للمرجع فقط، المواد المسندة، النصاب الأساسي، نصاب التدريس، المتبقي، الانتظار، الاستثناءات، التوفر والرغبات.
- المراحل والصفوف والشعب.
- المواد وعدد الحصص الأسبوعية وقوالب المناهج القابلة للتعديل.
- الغرف والمعامل والمختبرات والملاعب والموارد وسعتها.
- الإسناد: مادة + فصل/مجموعة + معلم/معلمين + غرفة/موارد + عدد الحصص + نمط التوزيع.

## 3. الإسناد
يدعم الإدخال اليدوي، الإسناد الجماعي، والاستيراد. لا يقيد المعلم بتخصصه. يدعم اختياريًا: معلمين في حصة واحدة، دمج عدة فصول، تقسيم الفصل إلى مجموعات، ودروس مرتبطة بموارد.

## 4. العلاقات والقيود
واجهة موحدة تسمح باختيار نطاقات ثم تطبيق علاقة. النطاق قد يجمع معلمين، مواد، فصول، مراحل، غرفًا، أيامًا، حصصًا، أنماط أسابيع، أو إسنادات. يدعم المنع، المطلوب، المفضل، غير المفضل، التثبيت، التفريغ، التتابع، عدم التتابع، حدود يومية، الانتشار، التزامن، عدم التزامن، واستخدام الموارد.

## 5. إنشاء الجدول
قبل الحل ينفذ النظام Preflight ويكتشف التعارضات البنيوية. ثم يولد عدة حلول محسّنة. كل حل يعرض: نسبة/درجة جودة، سلامة القيود الإلزامية، تفصيل العقوبات، الرغبات غير المتحققة، مؤشرات العدالة، والبدائل.

## 6. محرر الجدول
- عرض المدرسة/المرحلة/الفصل/المعلم/المادة/الغرفة.
- سحب وإفلات.
- تبديل حصتين.
- كشف التعارض لحظيًا.
- اقتراح نقل بديل.
- إصلاح تلقائي موضعي.
- إصلاح بأقل تغييرات.
- قفل حصة أو نطاق أو كيان كامل.
- Undo/Redo.
- سجل التعديلات وإصدارات محفوظة.

## 7. الذكاء والتفسير
- لماذا وضعت هذه الحصة هنا؟
- ماذا يمنع نقلها؟
- ما أفضل بدائل النقل؟
- لماذا لم يصل الحل إلى 100%؟
- ما أقل شرط يمكن تخفيفه للحصول على حل؟
- أوامر عربية طبيعية تتحول إلى علاقات بعد معاينة واعتماد المستخدم.

## 8. الانتظار والبدائل
يحسب النظام عبء المعلم. يمكن أن يصل مجموع التدريس والانتظار إلى الحد الإداري المحدد (مثال 24)، مع استثناءات وحدود خاصة. عند الغياب يقترح بدلاء مع تفسير الترتيب وفق الفراغ، العبء، العدالة، التخصص عند تفعيله، والقيود.

## 9. الاستيراد والتكامل
- Excel/CSV مع Mapping ذكي للأعمدة ومعاينة قبل الإدخال.
- قوالب مناهج قابلة للحفظ.
- استيراد الملفات الرسمية المتاحة من نور ومدرستي.
- تكامل API فقط عندما يكون رسميًا ومصرحًا به.

## 10. المخرجات
PDF، Excel، صورة، طباعة A4/A3، ملون/أبيض وأسود، شعار وبيانات المدرسة، QR اختياري. جداول: العام، المرحلة، الفصل، المعلم، المادة، الغرفة، المختبر، الانتظار، والغياب اليومي.

## 11. المستخدمون والصلاحيات
مدير، وكيل، مسؤول جداول، مشرف، معلم، ومشرف إدارة. صلاحيات دقيقة حسب المؤسسة والوحدة والعملية، مع Audit Log.

## 12. التعدد اللغوي
العربية RTL هي الافتراضية. الإنجليزية LTR اختيارية دون تغيير نموذج البيانات أو منطق الأعمال.
