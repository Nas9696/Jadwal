# PM-002 Scope Gate

PM-002 may begin only after PM-001R2 is complete.

PM-002 then owns the school-data configuration experience: academic years/terms, shifts, week patterns, day/period/break setup, stages/grades/sections, teachers/subjects/resources, teaching assignment CRUD + bulk editor, and import preview/mapping foundations.

It must consume the corrected calendar and scheduler contracts from PM-001R2 rather than redefining them in UI code.
